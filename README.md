## Tech Stack

### Frontend
- ReactJS
- SCSS
- Axios
- Node.js / npm

### Backend
- Python
- Flask
- SQL Server
- MySQL

## Project Structure

backend/
frontend/
database/
docs/

## Backend Setup

cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py

Backend runs at:

http://localhost:5000

## Frontend Setup

cd frontend
npm install
npm start

Frontend runs at:

http://localhost:3000
